## 📁 Struktur Repositori

```text
belajar/
├── Background/        # Koleksi aset gambar latar belakang (Unsplash)
├── Wedding/           # Mini-project halaman acara pernikahan & countdown timer
├── belajar-html/      # Modul & latihan materi HTML5 dan CSS (Dasar, Layouting, CSS3)
└── belajar-js/        # Modul & eksperimen JavaScript interaktif
```

---

## 📦 Detail Modul & Direktori

| Folder | Deskripsi & Isi Utama | Cara Menggunakan |
| :--- | :--- | :--- |
| **`Wedding/`** | Landing page acara pernikahan dilengkapi dengan *countdown timer* interaktif dan galeri foto. | Buka `index.html` langsung di browser. |
| **`belajar-html/`** | Modul pembelajaran terstruktur meliputi `CSS_Dasar`, `CSS_Layouting`, dan `CSS3`. | Pilih subfolder materi, lalu buka `index.html`. |
| **`belajar-js/`** | Latihan manipulasi DOM dan logika JavaScript interaktif. *(Catatan: memuat file skrip eksperimen dasar)*. | Buka `index.html` di browser atau jalankan skrip via terminal. |
| **`Background/`** | Koleksi aset gambar resolusi tinggi untuk kebutuhan visual project lain. | Digunakan sebagai aset statis web. |

## 🚀 Cara Menggunakan Repositori Ini

Repositori ini dirancang tanpa *overhead* dependensi yang rumit. Sebagian besar materi dapat dijalankan langsung di peramban web (*browser*).

1. **Kloning Repositori**
   ```bash
   git clone https://github.com/zakiafuadi925-ops/belajar.git
   cd belajar
   ```

2. **Menjalankan Proyek / Modul**
   - **Modul HTML/CSS/JS:** Cukup buka file `index.html` dari masing-masing direktori materi di browser pilihanmu (atau gunakan ekstensi *Live Server* di VS Code).
   - **Proyek Wedding:** Masuk ke folder `Wedding/` dan buka file `index.html`.

## 🛠️ Teknologi yang Dipelajari

- **HTML5**: Penataan struktur dokumen web yang semantik.
- **CSS3**: *Styling*, teknik *layouting* (Flexbox/Grid), dan desain responsif.
- **JavaScript (ES6+)**: Logika pemrograman interaktif dan manipulasi DOM.
- **Git & GitHub**: Praktik alur kerja kontrol versi (*version control*).
