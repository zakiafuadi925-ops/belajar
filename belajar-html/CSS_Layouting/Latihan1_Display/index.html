Latihan 1 Display

Latihan ini bertujuan untuk memahami penggunaan properti display dalam CSS. Properti display digunakan untuk menentukan bagaimana elemen HTML ditampilkan di halaman web. Dalam latihan ini, kita akan mencoba beberapa nilai display seperti block, inline, dan inline-block untuk melihat perbedaannya.
